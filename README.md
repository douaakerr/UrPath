# UrPath – Develop Yourself. Build Your Path.

UrPath is an AI-powered agentic learning platform that helps users achieve their learning goals through personalized assessments, adaptive learning roadmaps, and intelligent learning assistance.

### Features
- AI-generated knowledge assessments.
- Personalized learning roadmaps.
- Interactive quizzes and exercises.
- Learning progress tracking and analytics.
- AI-powered learning assistant.

### Tech Stack
- **Frontend:** React, Vite, JavaScript, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Qdrant
- **AI:** NVIDIA AI API

### Deployment
- **Frontend:** Vercel
- **Backend:** Render
